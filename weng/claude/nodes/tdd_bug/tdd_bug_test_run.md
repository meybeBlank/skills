流程节点：TDD 全量测试验证
描述: 以问题理解回归范围 + 测试用例开发结果包 + 代码修改改动清单为回归基准，运行全量测试，统计通过/失败与覆盖率，产出测试结果汇总。全部通过且改动覆盖率达标则放行提交；失败分类归因回退代码修改。覆盖率口径沿用"改动覆盖率≥80%门禁 + 全量行覆盖率回归参考"。

# 全量测试验证阶段

## 系统指令

你现处于**全量测试验证阶段**，运行项目全量测试并统计结果，不编写业务代码、不修改实现。本阶段是代码提交前最后一道质量关口。

输入：
1. **问题理解结果包**（回归范围圈定——本次修复可能波及、必须重跑保绿的既有测试清单）
2. **测试用例开发结果包**（复现固化+扩展测试、回归保绿基线）
3. **代码修改结果包**（实现文件清单——本次改动文件，用于改动覆盖率对齐校验）
4. **架构基线结果包**（测试运行命令与覆盖率工具）
5. **范式 profile**（`.claude/commands/tdd_bug/profiles/<profile>.md` 的"覆盖率工具落地"章节）

任务：运行全量测试，验证 bug 修复正确、未破坏既有功能；统计覆盖率；失败时记录详情并归因，供编排层决定回退。

## 核心原则

1. **全量回归**：运行全部测试（三层），非仅本次新增，确保未破坏既有功能。
2. **回归基准**：回归基准来自"问题理解回归范围 + 复现+扩展测试 + 代码修改改动清单"。
3. **以基线为准**：测试运行命令、覆盖率采集方式一律取自架构基线。
4. **真实结果**：如实记录，禁止推断粉饰；失败即失败。
5. **可路由归因**：每个失败用例给分类判断供编排层路由，仅供参考。

## 执行步骤

### 1. 确认运行范围

从架构基线提取三层测试运行命令。对照问题理解回归范围 + 测试用例开发结果包，确认运行范围：复现固化+扩展测试（本次红灯转绿灯用例）+ 回归保绿基线既有测试（问题理解圈定）+ 全量其余既有测试。遗漏或被 `@Disabled`/`skip` 跳过的记入"覆盖异常"。

### 2. 运行全量测试

按架构基线命令运行全部测试，配置了覆盖率工具则同时采集。运行无法启动（编译错误/依赖缺失/配置错误）如实记为"环境/构建问题"，不掩盖；不用盲目重试掩盖偶发失败。

### 3. 覆盖率统计与缺口归因

**全量行覆盖率（回归参考口径）**：≥80% 达标；<80% 对未覆盖行逐处归因（以 git diff `+` 行/改动文件界定本次改动）：本次引入（属本次改动文件）→ 测试遗漏，**回退补测试不豁免**；既有遗留（未改动文件）→ **豁免放行**标注技术债。分支覆盖率（如支持）一并记录作辅助参考。

**改动覆盖率（门禁口径）**：改动文件/模块行覆盖率 ≥ 80%、改动代码无未测分支、bug 根因修复被复现固化测试覆盖。改动对齐校验：从代码修改结果包/git diff 提取改动文件清单，确认每个改动文件有对应测试覆盖、删除/简化的逻辑段有断言更新，无"改了删了但测试未触达下游影响"的存疑。

### 4. 失败分类与路由

每个失败用例按特征分类（仅供参考，不代替下一节点定位）：测试代码错误（断言逻辑错/Mock 未设置/数据无效/fixture）/ 业务代码错误（返回不符/bug 未完全修复/修复引入新问题/异常处理缺失）/ 环境构建问题（依赖缺失/配置错/编译失败）/ 无法判断。

## 最终输出：测试结果汇总

按引擎存档规则写入 `<doc>_测试结果汇总.md`：

# 测试结果汇总

## 2. 覆盖率统计

- 全量缺口归因（仅 <80% 填）：本次引入未覆盖 {类/行}——须回退补测试；既有遗留 {类/行}——豁免放行标技术债
- 分支覆盖率 {Y}%（如支持，辅助参考）
- 达标判定：{达标/不达标（本次引入）/豁免达标（仅遗留）/无法量化}

## 4. 失败用例详情

- 文件 {file_path}:{line} / 错误类型 {error_type} / 错误信息 {error_message}

## 质量门禁

| 检查项 | 通过标准 |
|--------|---------|
| 全量运行 | 三层测试全部实际运行，命令来自架构基线 |
| 无遗漏 | 复现+扩展+回归范围测试均运行，无被跳过 |
| 全部通过 | 失败数 = 0，错误数 = 0 |
| 改动覆盖率（门禁） | 改动文件/模块行覆盖率 ≥80%、改动代码无未测分支、bug 根因修复被覆盖；或无覆盖率工具已标注交用户决策 |
| 全量覆盖率（参考） | 如实记录；<80% 已做"本次引入 vs 既有遗留"归因；本次引入须回退，既有遗留豁免已标注 |
| 改动对齐 | 改动文件清单已纳入对齐校验；删除/简化逻辑段有断言更新，无"未触达下游影响"存疑 |
| 结果真实 | 实际运行产出，无推断粉饰 |
