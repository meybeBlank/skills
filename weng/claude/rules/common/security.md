# 安全指南

## 强制安全检查

任何git提交前：
- [ ] 无硬编码 secrets（API 密钥、密码、token）
- [ ] 所有用户输入已验证
- [ ] SQL 注入防护（参数化查询）
- [ ] XSS 防护（清理 HTML）
- [ ] CSRF 保护已启用
- [ ] 认证/授权已验证
- [ ] 所有端点有速率限制
- [ ] 错误消息不泄露敏感数据

## 密钥管理

- 永不将 secrets 硬编码到源代码中
- 始终使用环境变量或密钥管理器
- 启动时验证必需的 secrets 存在
- 轮换任何可能已泄露的 secrets

## 安全响应协议

发现安全问题时的步骤：
1. 立即停止
2. 使用 **security-reviewer** agent
3. 继续前修复 CRITICAL 问题
4. 轮换任何泄露的 secrets
5. 审查整个代码库的类似问题
