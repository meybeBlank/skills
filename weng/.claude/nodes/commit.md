# 流程节点：Git 提交

## 目标

汇总所有步骤产出，生成提交信息，调用已有的 `git_commit_push` skill 执行代码提交。

## 前置条件

- 全部测试通过
- 所有代码改动已完成

## 执行流程

### 1. 汇总工作流产出的改动信息

回顾整个工作流程

### 2. 生成提交信息草稿

基于汇总信息生成符合 Conventional Commits 规范的提交信息：

```
<type>(<scope>): <简短描述>

## 变更摘要
- <改动要点1>
- <改动要点2>

## 测试覆盖
- 单元测试：{count} 个，全部通过
- 集成测试：{count} 个，全部通过

## 审查记录
- 代码审查：通过（{迭代次数} 轮）
- 测试审查：通过（{迭代次数} 轮）

## 回退历史
- {如有回退，列出每次回退原因}

@fengz
```
### 3. 调用 git_commit_push skill

调用已有的 `git_commit_push` skill，将步骤3生成的提交信息作为参数传入
